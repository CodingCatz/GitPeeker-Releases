# GitPeeker

換個方式，看見專案。
文件、網站與影音，在同一個桌面視窗預覽，無須完整 clone 儲存庫。

[下載最新發行](https://github.com/CodingCatz/GitPeeker-Releases/releases/latest)

- Windows 10／11 x64。提供安裝版（Setup）與免安裝版（Portable）；不需要 Node.js、Rust 或 Git。
- 0.6 起，標題列的「檢查更新」可取得新版。確認後會背景下載、驗證、正常關閉並背景重開。
- 同一台電腦、同一個作業系統帳號下，安裝／免安裝與後續改版共用登入與設定。請勾選「記住登入」，讓系統安全儲存可在重開後還原。
- 檢查更新不需要 GitHub 登入，不消耗 GitHub REST API 額度。讀取私人儲存庫仍需本人授權。
- 更新清單有 Ed25519 簽章，安裝檔另核對 SHA256；目前尚無 Windows Authenticode 簽章。
- macOS 桌面安裝包尚未提供。

本庫只公開已發布程式、更新清單及驗證附件。原碼儲存庫維持私人。
